<objective>
Wire the two mechanisms built in Wave 1 into the UI surfaces an operator actually uses:
show agent-group counts on the Organization Templates page (mirroring how every other
asset group's counts already render there), and add a "Push mesh to Vapi" action next to
the existing "Sync from Vapi" button on the Connected Assistants table.

Purpose: `createTemplateFromCurrentOrg`/`installSnapshotIntoOrg` already loop over
`OrgTemplateAssetGroup` generically, and the settings page already renders its asset-group
checkboxes from `ASSET_GROUPS`/`ASSET_GROUP_LABELS` — so adding `'agents'` in 139-01
required zero UI changes for the CHECKBOX. What's still hardcoded is the per-group COUNT
display (`snapshotCounts()` in actions.ts and the counts array in the manager component,
both list named fields, not a loop over `ASSET_GROUPS`) — this plan updates those two spots.
Separately, `pushAssistantConfig()` (139-04) exists as a library function with no caller
anywhere in the app; this plan gives it one.

Output: template list rows show an agents count; each row in the assistant mappings table
gets a "Push config" action.
</objective>
