- Voice and text share agent definitions; channel overrides express differences.
- Explicit Vapi functions can directly call mapped specialists; ambiguous intents use an orchestrator.
- Voice normally permits at most one internal specialist model invocation before deterministic action execution.
- Direct tool permission must be separated from delegation permission in Phase 132.
- Every Xphere-owned generative call must use OpenRouter; embeddings are evaluated separately.
- Action Engine remains the unique provider execution boundary.
- `assistant_mappings.entry_agent_id` is nullable, additive, tenant-safe, and has no Phase 131 production backfill.
- Phase 131 creates foundation only and does not cut production Vapi traffic over.
