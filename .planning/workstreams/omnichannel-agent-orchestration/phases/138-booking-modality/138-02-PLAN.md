<objective>
Wire the contracts from Plan 138-01 into the one place they actually change behaviour: the
widget/text runtime (`buildWorkflowTools()` + `runAgent()`). The engine, not the prompt
author, now decides whether `book_appointment` can be called without an address and what
the Booking specialist is told about it.

Voice stays explicitly out of reach in this plan: the Vapi function schema lives on Vapi's
side, nothing in this codebase writes to it (`src/lib/vapi/sync-assistants.ts` only reads
from Vapi), and building that outbound sync is Phase 139's job. Cuts & Culture's voice
prompt keeps its hardcoded "never ask" sentence until 139 gives it a way to read this
setting instead — this plan does not touch
`.planning/workstreams/omnichannel-agent-orchestration/canary/vapi-receptionist-prompt.md`.
</objective>
