## The thing most likely to be misread

`invokeAgent` has **no production callers**. The widget calls `runAgent` directly and
`/api/vapi/tools` calls `executeAction` directly. So the gateway, specialist routing and the
channel routing switch are built and tested but not on any request path — flipping a routing
row today changes nothing. Runbook step 5.0 is the human code change that wires it.

What phases 132-134 put *inside* `runAgent` and the Vapi route is live today.

## Environment

- Full suite fails ~30 files for live-database and module-resolution reasons. One of those
  turned out to be a real security leak, so audit newcomers rather than assuming noise.

  being down makes static generation slow and flaky, but it passes on retry.
