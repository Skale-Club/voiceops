## Known debts

- `scripts/provision-canary-graph.ts` does not create `agent_prompt_versions`; without one `resolveAgent()` refuses the agent. The tenant was fixed by hand. **A fresh run on another tenant produces six unusable agents.** Fix the script before any reuse.
- On voice in `specialist` mode, write tools (`book_appointment` etc.) still go direct to the Action Engine, never through the Booking specialist. Deliberate, to keep the ingress-scoped idempotency key; the "only Booking writes" invariant therefore only bites on the widget.
- Vapi has no outbound sync — prompt and tool schema changes are manual PATCHes. Phase 138 needs one (see its context) to carry `customerAddress` into the Vapi function schema.
- `tests/manual/*` hit live services and are outside the release gate on purpose.
